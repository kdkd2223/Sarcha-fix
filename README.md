# Arca-13 Admin Panel

Закрытая админ-панель для проекта Arca-13.  
Работает на **Cloudflare Workers + D1** (бесплатный тариф).

## Возможности

- Авторизация (логин / пароль), защищённые сессии (HttpOnly cookie)
- Роли: ГА, Зга, Старший администратор, Модератор — права проверяются на сервере
- Dashboard, Заметки, Новости, События, Правила, Статистика, Журнал действий, Уведомления, Состав, Управление администраторами
- Пароли только в виде bcrypt-хэшей
- Все важные действия пишутся в журнал
- Тёмный современный UI, адаптив под мобильные

## Требования

- Node.js 18+
- Аккаунт Cloudflare
- Wrangler CLI

## Быстрый старт

```bash
cd arca13-admin
npm install
```

### 1. Создать D1 базу

```bash
npx wrangler d1 create arca13-admin-db
```

Скопируйте `database_id` из вывода в `wrangler.toml` (поле `database_id`).

### 2. Применить миграции

Локально:
```bash
npx wrangler d1 execute arca13-admin-db --local --file=./migrations/0001_init.sql
```

На продакшене:
```bash
npx wrangler d1 execute arca13-admin-db --file=./migrations/0001_init.sql
```

### 3. Секрет сессий

В `wrangler.toml` замените `SESSION_SECRET` на длинную случайную строку  
или задайте через:

```bash
npx wrangler secret put SESSION_SECRET
```

### 4. Локальная разработка

```bash
npx wrangler dev
```

Откройте http://localhost:8787

### 5. Деплой

```bash
npx wrangler deploy
```

Сайт будет доступен на `https://arca13-admin.<your-subdomain>.workers.dev`

## Первый вход

- **Логин:** `ga`
- **Пароль:** `ChangeMe123!`

**Сразу смените пароль** через раздел «Управление» (или создайте нового ГА и удалите этот аккаунт).

## Безопасность

- Нет публичных страниц с админ-данными
- Сессии в HttpOnly + Secure + SameSite=Strict cookie
- Пароли — bcrypt (cost 10)
- API без валидной сессии возвращает 401
- Недостаточно прав — 403
- Действия логируются

## Важно

- Система банов/предупреждений **не** реализована — используется Juniper Bot
- Не храните и не выкладывайте `wrangler.toml` с реальными секретами в публичные репозитории
- После деплоя смените пароль ГА
